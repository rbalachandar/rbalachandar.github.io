bionexus agents run the scientific method

Agentic science that can be graded

BioNexus is an agentic science system that runs experiments end to end — hypothesis portfolios, safety-gated labs (simulated or real instruments), verdicts with confidence intervals against pre-registered criteria, and tamper-evident provenance. Drug-discovery first, domain-agnostic core.

Python · FastAPI · React MCP hash-chained provenance Apache-2.0

01 · 60-second demo

A scripted campaign on the production machinery (simulated numbers): a borderline result abstains, an orthogonal method refutes a plausible-looking hit, confirmation passes only on agreement — every step sealed in a verified hash chain.

02 · What it does

Hypothesis portfolios
Agents propose and rank testable hypotheses with mechanism, predicted values, and pre-registered refuted-if clauses — before any data exists.
Safety-gated execution
Every submission passes a policy engine the agent cannot modify: toxicophore screening, BSL limits, DURC refusal, operator halt switch, authorization matrix.
Honest verdicts
IC50s and interface scores carry confidence intervals; a CI straddling the gate returns inconclusive, never a coin-flip dressed as a result.
Real instruments, honestly labeled
Plate readers, Opentrons robots (contract-pinned driver), MCP instrument servers, and sandboxes — simulators are labeled simulated; hardware paths raise rather than fake.
Tamper-evident provenance
Every step lands in a hash-chained store enforced by database triggers; Merkle anchoring makes the record externally checkable.
Graded by its own harness
24 scored tasks in CI — hit recovery, verdict honesty, adaptive dosing, sandbox isolation. Mean 0.954, all pass; abstentions are graded down, not smoothed over.

03 · Architecture

Five core interfaces (model, lab, sandbox, provenance, tools) behind one gateway; governance lives in code the agent cannot reach.

04 · Proven on real data — including negative results

  • 98.9% agreement, zero false actives reproducing an NIH MLPCN screening cascade from the lab's own deposited raw tables — with 14 honest abstentions where confidence intervals straddled the gate.
  • A published negative result: fixed-reference IC50 rules do not port to self-normalized qHTS deposits — found, tested, and reported as such.
  • Prospective GPU experiment: 82 AI-designed PD-L1 binders + 30 matched controls showed that interface-confidence scores separate designs from controls as a group but cannot rank individuals — the platform's pre-registered refutation clauses caught it, and the negative result is part of the record.
